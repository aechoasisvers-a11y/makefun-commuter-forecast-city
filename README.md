A one-line weather forecast for the invented city of Drizzlewick, where even the clouds queue politely at the bus stop.

## Entry

> Drizzlewick: light rain, 14°, and the clouds have agreed to queue politely behind the bus shelter. Umbrellas optional, dignity intact.

## Run

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## Entry

"Drizzlewick: light rain, 14°, and the clouds have agreed to queue politely behind the bus shelter. Umbrellas optional, dignity intact."

134 characters, one line, no trailing newline.

## How it works

`main.py` (pure stdlib Python 3.13, `import os` only) writes the entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), after a self-check that it is 1–140 characters, not whitespace only, one line, and has no leading or trailing spaces.
